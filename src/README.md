# src/ - Исходный код приложения

Главный каталог исходного кода сервера телеметрии. Содержит точку входа, конфигурацию путей и все функциональные модули приложения.

## Структура

```
src/
├── main.cpp              — Точка входа (main)
├── paths_config.h.in     — Шаблон конфигурации путей (CMake → paths_config.h)
├── db/                   — Модуль работы с базой данных PostgreSQL
├── server/               — ZeroMQ-сервер для приёма телеметрии
├── gui/                  — Графический интерфейс (ImGui / ImPlot)
└── osm/                  — Модуль карты OpenStreetMap и тепловых карт
```

## Точка входа - [`main.cpp`](main.cpp)

Файл `main.cpp` выполняет следующую последовательность:

1. **Подключение к PostgreSQL** - вызов [`db_connect()`](db/db.hpp) из модуля [db/](db/).
2. **Загрузка истории** - [`loadHistoryFromDatabase()`](db/db.hpp) загружает накопленные точки из БД для отображения на карте.
3. **Настройка кэша тепловой карты** - путь к каталогу PNG-тайлов задаётся через `HEATMAP_CACHE_ROOT` (из `paths_config.h`).
4. **Запуск ZMQ-сервера** - в отдельном потоке вызывается [`run_server()`](server/server.hpp) из модуля [server/](server/).
5. **Асинхронная генерация тепловой карты** - [`heatmap_startup_async()`](osm/heatmap.hpp) запускает фоновый рендеринг heatmap.
6. **Запуск GUI** - [`run_gui()`](gui/gui.hpp) из модуля [gui/](gui/) — блокирующий вызов (основной цикл рендеринга).
7. **Завершение** - после закрытия окна останавливается сервер, очищаются ресурсы heatmap, закрывается соединение с БД.

## Конфигурация путей - [`paths_config.h.in`](paths_config.h.in)

CMake-шаблон, из которого при сборке генерируется `paths_config.h`. Определяет:

- `HEATMAP_CACHE_ROOT` - каталог для кэша PNG-тайлов тепловой карты.
- `PROJECT_SOURCE_ROOT` - корень исходников проекта.

## Глобальные переменные

В `main.cpp` объявлены глобальные переменные, используемые всеми модулями (см. [`osm/types.hpp`](osm/types.hpp)):

| Переменная | Тип | Назначение |
|---|---|---|
| `current_telemetry` | `TelemetryData` | Текущее состояние телеметрии (координаты, сигнал, история) |
| `mtx` | `std::mutex` | Мьютекс для синхронизации доступа к `current_telemetry` |
| `log_messages` | `vector<string>` | Лог событий для отображения в GUI |
| `running` | `bool` | Флаг работы сервера и GUI-цикла |
| `packet_counter` | `int` | Счётчик принятых пакетов |
| `con` | `PGconn*` | Дескриптор соединения с PostgreSQL |
